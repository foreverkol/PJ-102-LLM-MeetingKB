### 2.2 集成策略

- ✅ **只读**：项目不修改任何源文件

- ✅ **独立副本**：即使源目录变化，本项目不受影响
- ❌ **不实时同步**：避免复杂的状态管理

## 3. 与 LLM Provider 的集成

### 3.1 当前支持（按优先级）

1. **MiniMax M3**（默认，王老师指定）
   - base_url: `https://api.minimaxi.com/v1`
   - 端点: `text/chatcompletion_v2`
   - 模型: `MiniMax-Text-01`
   - 区域: 中国

2. **DeepSeek**（备用）
   - base_url: `https://api.deepseek.com/v1`
   - 模型: `deepseek-chat`

3. **OpenAI**（备用）
   - base_url: `https://api.openai.com/v1`
   - 模型: `gpt-4o-mini`

4. **Anthropic**（备用）
   - base_url: `https://api.anthropic.com/v1`
   - 模型: `claude-3-haiku`

### 3.2 LLM Client 集成

```python
class LLMClient:
    def __init__(self, provider="auto"):
            # 从 env 读取 key
            self.minimax_key = os.environ.get("MINIMAX_API_KEY", "")
            ...
            
            # 自动选择
            if provider == "auto":
                if self.minimax_key:
                    provider = "minimax"
                ...
```

### 3.3 关键修复

⚠️ **MiniMax 中国区 base_url 是 `https://api.minimaxi.com/v1`**（不是 `api.minimax.chat`）
⚠️ **端点路径不含 `/v1` 前缀**（base_url 已含）
