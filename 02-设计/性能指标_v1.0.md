## 4. 性能优化点

### 4.1 已实施

- ✅ **规则处理 S1**：避免 LLM 调用
- ✅ **LLM 容错**：safe_json_parse
- ✅ **超时重试**：exponential backoff
- ✅ **限流处理**：429 自动重试

### 4.2 待优化（v1.1）

- ⏳ **批量调用**：合并多个小请求
- ⏳ **缓存机制**：相同内容跳过 LLM
- ⏳ **异步并发**：多个文件并行处理
- ⏳ **prompt 压缩**：减少 token 消耗

### 4.3 性能基准测试

```python
# 测试脚本（tests/benchmark.py）
def benchmark():
    times = []
    for sample in samples:
        start = time.time()
        process_one(sample, llm)
        times.append(time.time() - start)
    
    print(f"平均: {sum(times)/len(times):.1f}s")
    print(f"P50: {sorted(times)[len(times)//2]:.1f}s")
    print(f"P95: {sorted(times)[len(times)*95//100]:.1f}s")
    print(f"最大: {max(times):.1f}s")
```
