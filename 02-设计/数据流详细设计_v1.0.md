```markdown
一栋楼押给银行，银行都不要...

发言人西安票圈郭小艳   02:05

...
```

### 2.2 复制策略

```python
# 启动时一次性复制（不实时同步）
for f in SRC.glob("*_原文.md"):
    dst = PROJECT / "system/data/raw" / f.name
    shutil.copy2(f, dst)
```

**复制时机**：
- ✅ 项目启动时（一次性）
- ❌ 不实时同步（避免复杂性）
- ❌ 不增量同步（避免状态不一致）

## 5. 关键数据转换

### 5.1 文件名 → 日期
```python
m = re.search(r'(202\d)(\d{2})(\d{2})', filename)
date = f"{m.group(1)}-{m.group(2)}-{m.group(3)}"
```

### 5.2 内容 → content_hash
```python
import hashlib
content_hash = hashlib.sha256(content.encode()).hexdigest()[:12]
```

### 5.3 LLM 输出 → 结构化 JSON
```python
def safe_json_parse(content, default):
    # 移除 markdown 包裹
    content = re.sub(r"^```(?:json)?\s?```", "", content)
    # 提取 JSON 块
    m = re.search(r"\{[\s\S]*\}", content)
    if m: content = m.group(0)
    # 尝试解析
    try: return json.loads(content)
    except: pass
    # 修复尾随逗号
    content = re.sub(r",\s*}", "}", content)
    try: return json.loads(content)
    except: return default
```
