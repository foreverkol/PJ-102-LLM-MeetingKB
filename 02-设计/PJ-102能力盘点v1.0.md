## 🔄 五、核心处理流程

### 5.1 完整数据流

```
URL/录音转写/外部资料
       ↓
[raw] 原始层
       ├─ web_clipper.py 抓取
       ├─ 千问手工转写(历史)
       └─ raw_clips/clip_*.md
       ↓
[tier] 分类层
       └─ tier_classifier.py 自动推断
       ↓
[citations] 引用层
       ├─ raw2citations.py 规则抽取
       └─ llm_cite_extract.py LLM 抽取
       ↓
[wiki] 知识库层
       ├─ persons/ 99 张人物卡
       ├─ concepts/ 137 张概念卡
       ├─ meetings/ 15 张会议卡
       └─ compiled_*.md 4 张编译卡
       ↓
[Obsidian] 展示层
       ├─ .obsidian/concepts.base
       ├─ .obsidian/persons.base
       └─ CLAUDE.md
```

### 5.2 工程化流程

```
git commit
       ↓
post-commit hook
       ↓
codex_reviewer.py HEAD(自动 fallback)
       ↓
.kanban/index.html 更新
       ↓
qqbot 推送王老师
       ↓
STATE.json last_codex_review 更新
```
