### 2. **`load_state()` 无错误处理,会导致下游全崩**
**文件**: `scripts/feishu_notify.py:35-37`
```python

    state_file = PROJECT_ROOT / "STATE.json"
    return json.loads(state_file.read_text(encoding="utf-8"))
```
**问题**: `STATE.json` 不存在/格式错时直接抛 `FileNotFoundError`/`JSONDecodeError`,没有降级。飞书推送是 P1 通知,失败应该有明确报错而非 traceback。
**修复建议**:
```python

    state_file = PROJECT_ROOT / "STATE.json"
    if not state_file.exists():
        raise FileNotFoundError(f"STATE.json 不存在:{state_file}(王老师 v41 协议要求单一真值源)")
    try:
        return json.loads(state_file.read_text(encoding="utf-8"))

```

### 1. **`codex_review.py` 的 `--uncommitted` 参数处理错位**
**文件**: `scripts/codex_review.py:30-33`
```python
def run_review(target: str, output: str = None) -> tuple:
    if target == "--uncommitted":
        cmd = ["codex", "review", "--uncommitted"]
    else:
        cmd = ["codex", "review", "--commit", target]
```
**问题**: `--uncommitted` 是 argparse 的 flag,不该以 positional 参数形式传递。`nargs="?"` + default="HEAD" 意味着用户必须写 `python3 codex_review.py -- --uncommitted` 才能绕过 argparse。用户手册和实现不一致。
**修复建议**:
```python
parser.add_argument("--uncommitted", action="store_true", help="评审未提交变更")
parser.add_argument("target", nargs="?", default="HEAD", help="commit SHA")
...
if args.uncommitted:
    cmd = ["codex", "review", "--uncommitted"]
else:
    cmd = ["codex", "review", "--commit", args.target]
```

### 5. **三个文件都缺文件末尾换行符**
**文件**: 全部 3 个新文件最后一行
```
\ No newline at end of file
```
**问题**: POSIX 标准要求文本文件以 `\n` 结尾,缺换行符会导致:
- `cat` 命令输出和下一个 prompt 粘在一起
- 部分 git 工具(magit 等)显示警告
- 王老师的"严谨"标准是文件结尾 100% 干净

**修复建议**: 在每个文件末尾加一个 `\n`(可以用 `printf '\n' >> file` 或编辑器强制)。
