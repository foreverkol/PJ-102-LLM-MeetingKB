# 🔍 Codex 代码评审报告 · PJ-102

## 🚨 严重问题(必须修复)

### 1. 幂等性测试覆盖退化 — `03-执行/tests/unit/test_tier_classifier.py:98-110`

**问题**:
旧测试用 `add_tier_frontmatter(j_file, "citations")` 调用 **两次** 完整验证 `(True, False)`。新版本改为读 `current_tier` 后只调用 **一次**,分支处理:

```python
if current_tier:
    result = module.add_tier_frontmatter(j_file, current_tier)
    assert result is False   # 只测了"已设置返回 False"
else:
    result = module.add_tier_frontmatter(j_file, "citations")
    assert result is True    # 只测了"未设置返回 True"
```

**关键漏洞**:当 `current_tier` 为 `None` 分支,只验证首次返回 `True`,**没有再调一次验证 `False`** —— 幂等性的核心断言(重复调用安全)丢失了。函数名仍叫 `test_add_tier_frontmatter_idempotent`,但行为已不再是幂等性测试,这是**测试语义与名称不符**,违反 v42 协议(虚假汇报 — CI 绿灯 ≠ 真的验证了幂等性)。

**修复建议**:恢复双调用断言,并以参数化方式覆盖"有 tier / 无 tier / 不同 tier"三种场景:

```python
@pytest.mark.parametrize("existing_tier,new_tier,expected_first,expected_second", [
    (None, "citations", True, False),       # 无→设→幂等
    ("citations", "citations", False, False), # 同 tier→幂等
    ("citations", "principles", False, False), # 不同 tier→跳过(按需)
])
def test_add_tier_frontmatter_idempotent(existing_tier, new_tier, expected_first, expected_second):
    ...
    r1 = module.add_tier_frontmatter(j_file, new_tier)
    r2 = module.add_tier_frontmatter(j_file, new_tier)
    assert (r1, r2) == (expected_first, expected_second)
```
