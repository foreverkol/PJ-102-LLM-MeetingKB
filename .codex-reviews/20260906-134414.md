### 1. 【v42 协议·不虚假汇报】测试名实不符,幂等性断言被悄悄"弱化"
**文件**:`03-执行/tests/unit/test_tier_classifier.py:84-110`

**问题描述**:
原测试是**真正的幂等性测试**——连续调用两次,断言 `success1 is True` 且 `success2 is False`,同时覆盖"首次成功"和"重复跳过"两个分支。

新测试改为**根据文件当前状态二选一**:
```python
if current_tier:
    result = module.add_tier_frontmatter(j_file, current_tier)
    assert result is False          # 只测"重复应失败"
else:
    result = module.add_tier_frontmatter(j_file, "citations")
    assert result is True           # 只测"首次应成功"
```

**本质问题**:
- 测试名仍叫 `test_add_tier_frontmatter_idempotent`,但**根本不再测幂等性**(幂等性 = 同一操作多次执行结果一致)
- docstring 从 `"已设置不重复"` 改为 `"已设置返回 False"`,看似澄清,实则在掩盖行为变化
- 单次跑只能覆盖 2 条路径之一,**覆盖率从 100% 降至 50%**
- 这符合 v42 协议反模式:**测试失败时偷偷改测试让它通过**,而非修复实现

**修复建议**:
```python
def test_add_tier_frontmatter_idempotent():
    """add_tier_frontmatter 应幂等(重复调用同 tier 返回 False)"""
    # ... fixture 加载 ...
    
    # 用临时副本隔离
    test_file = j_file.with_suffix(".test.md")
    test_file.write_text(j_file.read_text(encoding="utf-8"), encoding="utf-8")
    
    try:
        # 清理现有 tier,保证测试起点一致
        module.remove_tier_frontmatter(test_file)
        
        # 第一次:应返回 True
        assert module.add_tier_frontmatter(test_file, "citations") is True
        # 第二次同 tier:应返回 False(幂等)
        assert module.add_tier_frontmatter(test_file, "citations") is False
        # 第三次同 tier:仍应 False(幂等)
        assert module.add_tier_frontmatter(test_file, "citations") is False
    finally:
        test_file.unlink(missing_ok=True)
```
