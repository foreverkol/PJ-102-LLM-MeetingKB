## 🔍 五、过程与逻辑详解

### 5.1 数据流(完整)

```
[数据源] 历史录音 / Web Clipper / 历史判断
       ↓
[raw 层] raw_clips/sample_S*.md
   - 真实样例读取(Web Clipper 抓的)
   - 或模拟样例生成(基于王老师核心业务)
       ↓
[citations 层] citations/cite_sample_S*_*.md
   - URL 提取(>0)
   - ## 标题提取(>5)
   - > 引用提取(王老师发言)
   - 1./2./3. 判断提取
       ↓
[wiki 层] wiki/wiki_S*.md
   - 主题介绍
   - 内容组成(按 type 分组)
   - 数据血缘图
   - 质量评分
```

### 5.2 关键设计

1. **真实数据优先**:数据源存在时直接读取(Web Clipper 已抓的文件),不存在时模拟生成
2. **3 类型 citation**:URL + heading + quote + judgment(4 类型)
3. **结构化 frontmatter**:每个文件都有可解析的 frontmatter
4. **质量评分多维度**:raw + citation + wiki + lineage
