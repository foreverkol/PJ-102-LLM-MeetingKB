## 1. 日常运维

### 1.1 启动跑批

```bash
# 1. 切换到代码目录
cd /mnt/d/BaiduSyncdisk/hermes/01-项目/PJ-102-LLM-MeetingKB/03-执行/code

# 2. 加载环境变量（从 ~/.hermes/.env）
export MINIMAX_API_KEY=$(grep ^MINIMAX_API_KEY= /home/administrator/.hermes/.env | cut -d= -f2)
export MINIMAX_CN_BASE_URL=$(grep ^MINIMAX_CN_BASE_URL= /home/administrator/.hermes/.env | cut -d= -f2)

# 3. 验证环境
echo "API key 长度: ${#MINIMAX_API_KEY}"  # 应 > 100
echo "Base URL: $MINIMAX_CN_BASE_URL"     # 应 = https://api.minimaxi.com/v1

# 4. 跑批
python3 pipeline.py --limit 10    # 测试 10 个
python3 pipeline.py               # 跑全部
```

| 条件 | 处理 |
|---|---|

## 6. 故障恢复流程

```bash

# 3. 或暂停跑批
# 等待服务恢复
```


## 7. 性能调优

### 7.1 监控指标

```python
# 加到 pipeline.py 末尾
total_time = time.time() - start
avg_time = total_time / success_count
print(f"平均: {avg_time:.1f}s")

if avg_time > 180:
    print("⚠️ 性能下降，建议检查 LLM 网络")
elif avg_time > 150:
    print("⚠️ 性能略低，建议优化 prompt")
```

### 7.2 优化建议

1. **prompt 压缩**：减少 token 消耗
2. **缓存机制**：跳过相同内容
3. **并发处理**：多文件并行（v2.0）
4. **批量调用**：合并小请求（v2.0）
