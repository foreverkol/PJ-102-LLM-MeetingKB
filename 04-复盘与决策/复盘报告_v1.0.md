## ⚠️ 关键问题与解决

### Q1: MiniMax 中国区 base_url 错误

**问题**: 最初用 `https://api.minimax.chat/v1/text/chatcompletion_v2` → 404
**根因**: base_url 不对
**修复**: 改为 `https://api.minimaxi.com/v1` + 端点 `text/chatcompletion_v2`
**教训**: 必须验证 base_url 而不只是复制代码

### Q2: Python 相对 import 失败

**问题**: `from ..llm_client import ...` 报 `attempted relative import beyond top-level package`
**根因**: `steps/` 子目录用相对 import 父目录失败
**修复**: 改为绝对路径 import（`sys.path.insert(0, parent_path)`）
**教训**: 子目录模块 import 父目录需用绝对路径

### Q3: PROJECT_ROOT 路径计算错误

**问题**: `PROJECT_ROOT = Path(__file__).parent.parent.parent.parent` → 错
**根因**: 多算了一层
**修复**: 改为 `.parent.parent.parent`（三层）
**教训**: 调试时必须 print 实际路径验证

### Q4: 跑批比预期慢

**问题**: 实际每个文件 135.8 秒（预期 90 秒）
**根因**: MiniMax API 响应慢 + 11 次 LLM 调用
**修复**: 接受现状，跑批时间 = 255 × 135.8 秒 = 9.6 小时
**教训**: 性能预估要预留 30% 缓冲
