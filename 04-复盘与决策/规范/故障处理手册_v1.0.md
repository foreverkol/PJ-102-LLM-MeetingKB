## 2. 常见故障

### F1: LLM API key 失效

**症状**:
```
❌ LLM 调用失败 (HTTP 401): Unauthorized
```

**根因**:
- API key 过期
- API key 被撤销
- 环境变量未设置

**解决方案**:

```bash
# 1. 检查 key 是否设置
echo $MINIMAX_API_KEY  # 应该返回长字符串

# 2. 检查 ~/.hermes/.env
grep MINIMAX_API_KEY /home/administrator/.hermes/.env

# 3. 重新设置
export MINIMAX_API_KEY="新的key"

# 4. 或从 ~/.hermes/.env 重新读取
source /home/administrator/.hermes/.env
export MINIMAX_API_KEY=$(grep ^MINIMAX_API_KEY= /home/administrator/.hermes/.env | cut -d= -f2)

# 5. 测试
python3 pipeline.py --limit 1 --no-llm  # 测试代码
```

**预防**:
- 定期检查 key 有效期
- 备份 key 到安全位置

### F2: 端点 URL 404

**症状**:
```
❌ LLM 调用失败 (HTTP 404): 404 Page not found
```

**根因**:
- base_url 错误（如用 `api.minimax.chat` 而非 `api.minimaxi.com`）
- 端点路径错误

**解决方案**:

```bash
# 正确的 base_url 和端点
export MINIMAX_CN_BASE_URL="https://api.minimaxi.com/v1"

# 测试
curl -X POST "https://api.minimaxi.com/v1/text/chatcompletion_v2" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $MINIMAX_API_KEY" \
  -d '{"model":"MiniMax-Text-01","messages":[{"role":"user","content":"test"}],"max_tokens":10}'
```

**预防**:
- 配置文件 `.env.example` 注释正确的 base_url
- 启动时检查

### F3: JSON 解析失败（LLM 返回非标准）

**症状**:
```
⚠️  LLM 调用失败: Expecting ',' delimiter
```

**根因**:
- LLM 返回 markdown 包裹但解析失败
- LLM 返回含中文逗号

**解决方案**:

代码已实现 `safe_json_parse()`，会自动处理：
```python
def safe_json_parse(content, default):
    # 1. 清理 markdown
    # 2. 提取 JSON 块
    # 3. 尝试解析
    # 4. 修复尾随逗号
    # 5. 返回默认值（兜底）
```

如果仍然失败，可以：
```python
# 在 steps/s?_*.py 中调整 max_tokens 或 prompt
# 增加更明确的 JSON 输出要求
```

**症状**:

**解决方案**:


### F5: 限流（429）

**症状**:
```
⚠️  限流，等待 2s 后重试...
⚠️  限流，等待 4s 后重试...
```

**根因**:
- 调用频率过高
- 共享 API key 配额

**解决方案**:

代码已实现 exponential backoff，自动重试。如果频繁触发：
```python
# llm_client.py 中增加 sleep
import time
time.sleep(1)  # 每个调用后 sleep 1 秒
```

### F6: 网络中断

**症状**:
```
❌ LLM 调用失败 (HTTP 503): Service Unavailable
```

**解决方案**:

```bash
# 1. 检查网络
ping api.minimaxi.com

# 2. 等待网络恢复

# 3. 重跑（自动跳过已完成的）
python3 pipeline.py
```

### F9: 项目目录路径错

**症状**:
```
❌ 找不到 index: /mnt/d/.../system/data/index.json
```

**解决方案**:

```bash
# 1. 检查项目目录
ls /mnt/d/BaiduSyncdisk/hermes/01-项目/PJ-102-LLM-MeetingKB/

# 2. 检查 system/data/
ls /mnt/d/BaiduSyncdisk/hermes/01-项目/PJ-102-LLM-MeetingKB/system/data/

# 3. 重新复制源文件
cd /mnt/d/BaiduSyncdisk/hermes/01-项目/PJ-102-LLM-MeetingKB/system/src
python3 -c "
import shutil
from pathlib import Path
SRC = Path('/mnt/d/BaiduSyncdisk/hermes/修改发言人转化')
DST = Path('system/data/raw')
for f in SRC.glob('*_原文.md'):
    shutil.copy2(f, DST / f.name)
print('复制完成')
"
```
