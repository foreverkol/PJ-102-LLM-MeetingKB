# PJ-102-LLM-MeetingKB · 风险与依赖 v1.0

## 风险评估

### 🔴 高风险
| 风险 | 描述 | 缓解 |
|---|---|---|
| 无 | 无 | - |

### 🟡 中风险

#### R1: MiniMax M3 限流
- **描述**：中国区 API 可能有 QPS/RPM 限制，242 个文件 × 11 次调用 ≈ 2662 次
- **触发条件**：连续快速调用返回 429
- **缓解**：
  1. 每个 LLM 调用后 sleep 0.5 秒
  2. 检测 429 错误 + exponential backoff（1s, 2s, 4s）
  3. 失败 3 次后跳过该步骤，记录到日志

#### R2: LLM JSON 解析失败
- **描述**：LLM 返回格式不稳定（markdown 包裹、尾随逗号、未转义引号）
- **触发条件**：约 5-10% 的 LLM 返回
- **缓解**：
  1. 已实现 `_safe_json_parse()` 容错
  2. 移除 markdown 包裹（```json）
  3. 提取 JSON 块（找 { ... }）
  4. 修复尾随逗号
  5. 失败返回默认值（不阻塞流程）

#### R3: 网络中断
- **描述**：长时间跑批过程中网络中断
- **触发条件**：超过 5 小时跑批
- **缓解**：
  1. 单文件独立处理（失败不影响其他文件）
  2. 状态保存到 system/state/
  3. 增量重跑（跳过已完成的）

#### R4: 源文件变化
- **描述**：源文件被修改/删除/新增
- **触发条件**：项目运行期间
- **缓解**：
  1. 启动时一次性复制（已复制 255 个）
  2. 不实时同步（避免复杂性）

### 🟢 低风险

#### R5: API key 失效
- **描述**：MiniMax API key 过期或失效
- **缓解**：从 `~/.hermes/.env` 读取，支持重新加载

#### R6: 磁盘空间不足
- **描述**：WIKI 输出占磁盘空间（预计 50-80 MB）
- **缓解**：检查可用空间（> 1 GB），不足时报警
