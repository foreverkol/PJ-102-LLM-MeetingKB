# PJ-102-LLM-MeetingKB · 项目范围与边界 v1.0

## 项目范围（In Scope）

### 必须做（MUST）
1. **12 步 LLM pipeline**：每步独立 LLM 调用，结果结构化
2. **5 类 WIKI 落地**：meeting / person / concept / judgment / comparison
3. **完全独立运行**：不依赖其他 PJ 项目
4. **源文件复制**：从 `修改发言人转化/` 复制到 `system/data/raw/`
5. **MiniMax M3 真实调用**：中国区 base_url + 端点修复
6. **JSON 容错解析**：处理 markdown 包裹、尾随逗号等
7. **CLI 接口**：支持 limit / no-llm / clear / provider 等参数

### 应该做（SHOULD）
1. **错误日志**：记录所有 LLM 失败和解析失败
2. **限流处理**：sleep + exponential backoff
3. **进度报告**：实时显示处理进度
4. **基本测试**：核心路径烟雾测试

### 可以做（COULD）
1. **Cron 调度**：daemon + monitor
2. **registry.db**：独立注册表（暂不实现）
3. **单元测试**：完整 unit 覆盖

### 不做（WON'T）
1. **❌ 不读取 PJ-001 任何 WIKI**：从零生成
2. **❌ 不修改源文件**：完全只读
3. **❌ 不共享 registry**：完全独立
4. **❌ 不依赖 PJ-001-07/PJ-001-08 任何代码**：独立写代码
