## REQ-001 项目本质与核心目标

**一句话定位**：基于 LLM 真实调用（MiniMax M3）+ 12 步 pipeline 的会议转写→知识库全流程处理，**完全独立**的项目。

### 核心目标
1. **可独立运行**：项目目录内代码+源文件+registry 可跑通 12 步 pipeline
2. **可重新生成**：从源文件 → WIKI，无需依赖其他项目
3. **可审计**：所有代码/文档/状态完整可追溯
4. **可隔离**：与 PJ-001 / PJ-001-07 / PJ-001-08 / PJ-001-111 **零依赖**

### 不做什么（边界）
- ❌ 不依赖 PJ-001 任何子项目代码
- ❌ 不读取 02-知识库/PJ-001/ 现有 WIKI（重新生成）
- ❌ 不修改修改发言人转化/ 源文件（只读）
- ❌ 不使用 PJ-001-07 的 registry.db
- ❌ 不使用 PJ-001-111 的代码

## REQ-002 功能需求

### FR-001 12 步全流程（每步独立 LLM 调用）

| 步骤 | 名称 | 输出 | LLM 调用 |
|---|---|---|---|
| S1 | 基础信息 | title/date/duration | ❌（规则）|
| S2 | 场景识别 | scene_type/perspective | ✅ |
| S3 | 标准摘要 | 一句话+背景+问题+方法+结果+洞察 | ✅ |
| S4 | FJV 三分法 | facts/judgments/values | ✅ |
| S5 | 隐性知识 | 体验性/判断性/关系性（3 次子调用）| ✅ ×3 |
| S6 | 5 类实体 | persons/orgs/concepts/products/projects | ✅ |
| S7 | 决策+行动 | decisions/action_items | ✅ |
| S8 | 风险+盲区 | risks/blindspots/uncertain | ✅ |
| S9 | 知识归类 | knowledge_type/tags/reuse_scenarios | ✅ |
| S10 | 认知提炼 | 思维框架 + 数字人素材 | ✅ |
| S11 | 价值评级 | relevance/actionability/innovation | ✅ |
| S12 | WIKI 落地 | 5 类 WIKI Markdown | ❌（写入）|

**总 LLM 调用**：约 11 次/文件（9 + 2 + 4）

### FR-002 LLM 调用

- **Provider**: MiniMax M3（中国区）
- **base_url**: `https://api.minimaxi.com/v1`（不是 api.minimax.chat）
- **端点**: `text/chatcompletion_v2`（base_url 已含 /v1）
- **Model**: MiniMax-Text-01
- **Temperature**: 0.3（保证一致性）
- **Max Tokens**: 500-2000（按步骤需求）

### FR-003 5 类 WIKI 产出

| 类型 | 命名 | 文件数/源 | 备注 |
|---|---|---|---|
| meeting | `meeting_{date}_{hash}.md` | 1 | 主文件 |
| person | `person_{hash6}-{name}.md` | 0-10 | 每个说话人 |
| concept | `concept_{date}_{hash}.md` | 1 | 聚合 |
| judgment | `judgment_{date}_{hash}.md` | 1 | 聚合 |
| comparison | `comparison_{date}_{hash}.md` | 1 | 聚合 |

### FR-004 数据来源

- **源文件**: `/mnt/d/BaiduSyncdisk/hermes/修改发言人转化/*_原文.md`
- **复制策略**: 启动时复制到 `system/data/raw/`（独立副本）
- **更新策略**: 增量同步（按需）

## REQ-003 性能需求

| 指标 | 目标 |
|---|---|
| 单文件处理时间 | < 2 分钟（含 11 次 LLM 调用）|
| 单文件成功率 | > 95% |
| 错误处理 | LLM 失败自动重试（3 次）|
| 限流处理 | sleep + exponential backoff |
| WIKI 落地 | 实时写文件 |

## REQ-004 质量需求

- ✅ FJV 真实数字（不靠关键词匹配）
- ✅ Judgment 是完整句（不是片段）
- ✅ Risk 带影响/应对建议
- ✅ 认知提炼（思维框架 + 数字人素材）
- ✅ 价值评级（量化 0-1）

## REQ-005 接口需求

### CLI 命令
```bash
# 全量跑
python3 pipeline.py

# 限制样本
python3 pipeline.py --limit 13

# 跳过 LLM（mock）
python3 pipeline.py --no-llm

# 指定 LLM provider
python3 pipeline.py --provider minimax

# 清空旧 WIKI
python3 pipeline.py --clear

# 干跑（不写文件）
python3 pipeline.py --dry-run
```

### Python API
```python
from pipeline import process_file
result = process_file("path/to/原文.md", provider="minimax")
```
